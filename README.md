# 리그 오브 레전드 경기력 평가를 위한 설계 및 활용

## 1. 개 요

---

LoL 솔로랭크는 매 경기 팀원이 무작위로 정해진다. 그래서 한 경기의 승패에는 본인의 플레이 외에 팀원의 실력이나 컨디션 같은 요소가 함께 섞인다. 챌린저처럼 상위권 플레이어끼리 실력 차이가 크지 않은 구간에서는 승률만으로 누가 더 잘하는지 가리기가 더 어렵다.

이 보고서에서는 경기 결과 대신 경기 도중의 기록을 이용한다. 매 분마다 각 라인이 상대 라인보다 얼마나 앞서 있었는지를 수치로 만들고, 이를 소환사별로 모아 개인의 경기력을 비교한다.

### 1.1 분석 데이터

Riot Games API에서 제공하는 한국 서버 챌린저 300명(2025년 4월 8일 기준)의 솔로랭크 경기를 사용한다. 기간은 2025년 1월 8일부터 4월 8일까지이며, 20분 이상 진행된 38,075경기가 대상이다.

경기마다 결과 정보(match)와 1분 간격의 진행 기록(timeline)이 있다. match에서는 승패, 패치 버전, 참가자별 포지션을, timeline에서는 분 단위 골드·경험치·CS·데미지와 킬·와드·오브젝트 같은 이벤트를 가져온다.

포지션 기록이 비어 있거나 겹쳐서 맞라인 상대를 정할 수 없는 641경기와, 2025 시즌 이전 패치(14.24)로 진행된 139경기를 제외한다.

특정 패치만 고르거나 일부를 추출하지 않고, 2025 시즌 패치(15.1~15.7) 경기는 모두 사용한다. 4장에서 TCI를 소환사 단위로 모아 비교하므로, 소환사마다 충분한 경기 수를 확보하는 것이 중요하기 때문이다. 최종 분석 대상은 37,295경기이다.

| 패치 | 15.1 | 15.2 | 15.3 | 15.4 | 15.5 | 15.6 | 15.7 | 합계 |
|---|---|---|---|---|---|---|---|---|
| 경기 수 | 8,264 | 5,636 | 7,509 | 5,692 | 4,923 | 3,514 | 1,757 | 37,295 |

### 1.2 경기력 평가를 위한 기본 방향

선행연구[[1]](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003327764)는 미드라이너 한 포지션만 분 단위로 평가하였다. 【선행연구 방법 요약 1~2문장】

본 연구는 평가 대상을 TOP, JUNGLE, MIDDLE, BOTTOM 네 라인으로 늘린다. BOTTOM은 원거리 딜러와 서포터 두 명의 기록을 합쳐 하나의 라인으로 계산한다.

모델은 라인마다 따로 학습한다. 입력은 그 라인의 플레이 기록 $\vec{x}$와 경기 시간 $t$, 출력은 그 시점의 팀 유리함 $y$이다. 학습된 모델이 내놓는 값을 해당 라인의 타임라인 기여도 지수(TCI)로 사용한다.

$$
TCI_{LANE} (\vec{x}, t ; \theta), ~~~\text{where}~~LANE \in \{ TOP,~JUNGLE,~MIDDLE,~BOTTOM\}  
$$

### 1.3 분석 목적

최종 목표는 챌린저 300명을 라인별 TCI로 비교하는 것이다. 평균뿐 아니라 초반과 후반 중 언제 강한지, 경기마다 기복이 얼마나 있는지도 함께 확인한다.

## 2. 변수 설정

---

### 2.1 타겟 변수 설정

$y$는 매 분 어느 팀이 얼마나 앞서 있는지를 나타내야 한다. 이를 위해 아래 후보들을 블루팀 합계 − 레드팀 합계로 계산해 비교한다.

- 골드, 경험치, CS, 챔피언에게 준 데미지
- 골드+경험치, 골드+CS, 골드+데미지, 골드+경험치+CS (단위가 다르므로 분별 표준편차로 나눈 뒤 더함)

선택 기준은 승패 예측 정확도이다. 각 분에서 후보값이 양수면 블루팀이 이긴다고 보고, 실제 결과와 맞는 비율을 계산한다. 게임 종료 시점 값은 승패 결과와 거의 같아서 비교에서 뺀다.

| 후보 | 5분 | 10분 | 15분 | 20분 | 25분 | 30분 |
|---|---|---|---|---|---|---|
| 골드 | | | | | | |
| 경험치 | | | | | | |
| CS | | | | | | |
| 데미지 | | | | | | |
| 골드+경험치 | | | | | | |
| 골드+CS | | | | | | |
| 골드+데미지 | | | | | | |
| 골드+경험치+CS | | | | | | |

【결과 해석 및 최종 선택 이유】

$y$에 사용한 지표는 피처에서 제외한다.

## 3. 경기력 지표 모델링

---

### 3.1 모델 선정

선형회귀와 XGBoost 두 모델을 비교한다.

선형회귀는 피처마다 가중치를 곱해 더하는 모델이다. 가중치를 보면 라인별로 어떤 기록이 팀 유리함에 크게 작용하는지 알 수 있어 기준 모델로 사용한다.

XGBoost는 결정 나무 여러 개를 순서대로 학습시키는 모델이다. 새로 추가되는 나무는 앞선 나무들이 틀린 만큼을 보정하도록 학습한다. 시간대에 따라 같은 기록의 중요도가 달라지는 것처럼 선형회귀로 표현하기 어려운 관계를 학습할 수 있다. 【손실 함수, 규제, 하이퍼파라미터 설명】

학습용과 평가용 데이터는 경기 단위로 8:2로 나눈다. 같은 경기의 연속된 분 데이터는 서로 비슷해서, 행 단위로 섞으면 같은 경기가 양쪽에 들어가 성능이 실제보다 높게 나오기 때문이다.

## 4. TCI 모델의 활용

학습한 모델로 경기마다 분 단위 TCI 그래프를 만들고, 한 소환사가 같은 라인에서 플레이한 경기들을 모아 다음 세 가지로 요약한다.

- 평균: 전체적으로 얼마나 앞서는지
- 추세: 시간이 지날수록 격차를 벌리는지, 좁혀지는지
- 변동성: 경기마다 기복이 큰지
